# 🇰🇿 Калькулятор зарплаты в Казахстане (salary-kz)

Современное веб-приложение, созданное на React, TypeScript и Vite, для расчета зарплаты (на руки и до вычета налогов) в Казахстане. Калькулятор точно учитывает текущие местные налоги, пенсионные взносы и отчисления на медицинское страхование.

## ✨ Особенности

- **Расчет Gross & Net (Грязными и Чистыми)**: Мгновенная конвертация вашей зарплаты до вычета налогов в сумму "на руки" и наоборот.
- **Детальная разбивка налогов**: Четко отображает удержания на основе актуальных налоговых настроек (`tax-config.ts`), включая:
  - Обязательные пенсионные взносы (ОПВ)
  - Индивидуальный подоходный налог (ИПН)
  - Взносы на обязательное социальное медицинское страхование (ВОСМС)
- **Визуальное распределение**: Интерактивные графики (`DistributionChart.tsx`), показывающие визуальную разбивку вашей зарплаты в сравнении с удержаниями.
- **Адаптивный дизайн**: Красивый, удобный для мобильных устройств интерфейс, созданный с помощью Tailwind CSS.

## 🛠 Технологии

- **Фреймворк**: [React](https://reactjs.org/) + [Vite](https://vitejs.dev/)
- **Язык**: [TypeScript](https://www.typescriptlang.org/)
- **Стилизация**: [Tailwind CSS](https://tailwindcss.com/)
- **UI Компоненты**: Доступные, переиспользуемые UI компоненты (`src/components/ui`)
- **Развертывание (Деплой)**: Автоматизированные процессы CI/CD через GitHub Actions (`deploy.yml`)

## 🚀 Как начать

### Требования
- Node.js (рекомендуется версия v18 или выше)
- npm, yarn или pnpm

### Установка

1. Клонируйте репозиторий:
   ```bash
   git clone <url-репозитория>
   cd salary-kz
   ```

2. Установите зависимости:
   ```bash
   npm install
   ```

3. Запустите сервер для разработки:
   ```bash
   npm run dev
   ```

4. Откройте браузер и перейдите по локальному URL, предоставленному Vite (обычно `http://localhost:5173`).

### Сборка для продакшена

Для создания сборки, готовой к продакшену, выполните:
```bash
npm run build
```
Собранные файлы будут сгенерированы в директории `dist`.

## 📂 Структура проекта

- `src/components/` - Основные компоненты приложения (`SalaryCalculator`, `SalaryInput`, `SalaryOutput`).
- `src/components/ui/` - Переиспользуемые элементы дизайн-системы (Accordion, Button, Card, Switch, Tabs и т.д.).
- `src/lib/` - Основная бизнес-логика:
  - `calculator.ts` - Математика и алгоритмы вычетов.
  - `tax-config.ts` - Константы для налоговых ставок Казахстана, МРП и МЗП.
- `src/hooks/` - Кастомные React хуки (например, `use-media-query.ts`).
- `.github/workflows/` - Пайплайны CI/CD.

## 📄 Развертывание (Деплой)

Проект настроен на автоматическое развертывание с использованием пользовательского скрипта `deploy.sh` и GitHub Actions.
